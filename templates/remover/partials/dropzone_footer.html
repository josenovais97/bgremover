{% load i18n_extras %} {% comment %} The bottom of an empty dropzone. Tool pages lay the dropzone beside a before/after demo with `items-stretch`, so the panel is as tall as the demo — which left most tools with a dashed box that was two thirds empty air while the visitor decided what to do. This is the part that decides whether they drop a file, and it was the emptiest thing on the page. Rather than shrink the panel, fill it with the two things a first-time visitor does not know and would want to: that they can paste straight from the clipboard, and that the file is not going anywhere. Both are true of every tool, which is why this is shared rather than written per page. The paste hint is hidden on touch devices via `hidden sm:flex` — there is no Ctrl+V on a phone, and advertising a shortcut nobody can press is noise. Takes no parameters, deliberately. It used to accept an optional `formats` line — and because {% include %} inherits the parent context, it picked up the unrelated `formats` variable the converter and Instagram views already pass (their output format buttons) and rendered a raw Python list into the dropzone. Every dropzone already names its own accepted formats above the button, so the parameter was speculative as well as dangerous. {% endcomment %}
